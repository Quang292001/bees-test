# 💻 App Development Test - BEES Assignment

## Description
This project is a responsive user management page developed with React and TypeScript. It includes a data table that displays a list of 100+ users with pagination, sorting, dark mode toggle, and more.

## Features

✅ Core Functionality:
- Shows user details in a paginated table (default: 10 per page)
- Balance: formatted with `$` sign and thousand separator
- Email: clickable mailto link
- Registration: displayed as `yyyy-MM-dd` with tooltip (detailed date and time)

✅ Technical:
- Built with React, TypeScript, and Ant Design
- Type-safe: `TUser` interface included
- 100+ mock user data generated

✅ Bonus Features:
- ✅ Sorting by name, balance, registration date
- ✅ Filtering by name (search input)
- ✅ Dark mode toggle (light/dark theme)
- ✅ Loading spinner when fetching data
- ✅ Error handling when fetching fails

## Tech Stack
- React
- TypeScript
- Ant Design
- TailwindCSS (for some basic styling)
