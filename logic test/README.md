# 🧠 Logic Test - BEES Assignment

## Description
This directory contains the `processWithDelay` function written in TypeScript, which demonstrates the use of modern async/await patterns.

## Features
- ⏱ Processes each number with a 1-second delay between them
- 🧪 Returns a resolved Promise after completion
- ⚠️ Gracefully handles empty or invalid inputs
- ✨ Bonus:
  - Configurable delay time
  - Supports cancellation
  - Tracks progress percentage

### 1. Install dependencies

npm install -g ts-node typescript

### 2. run file
